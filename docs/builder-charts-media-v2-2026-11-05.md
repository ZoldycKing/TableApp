# Диаграммы и видео v2

5 ноября 2026 года. Продолжение [общего плана](no-code-builder-implementation.md).

## Результат для автора

В «Добавить элемент» доступны «Диаграмма» и «Видео» в существующем оформлении
конструктора. Для диаграммы автор выбирает внутреннюю таблицу, поле категорий
и расчёт: количество записей, сумму или среднее числового поля. Есть столбцы,
линия по датам и круговая диаграмма. Поля и варианты настройки предлагаются
только для подходящих типов. Изменение таблицы сбрасывает несовместимые настройки.
Новый источник не выдаёт роли дополнительные права чтения.

Вкладка «Данные» использует общий отбор, сохранённое представление и поиск
источника. У линии настраивается группировка по дням или месяцам. Для столбцов
и круга выбирается число основных категорий; остальные объединяются в явно
названную группу. Добавление диаграммы внутрь повторяемого списка запрещено:
она агрегирует свой источник целиком.

Видео принимает прямую ссылку на воспроизводимый браузером файл и подпись.
Можно использовать общее связывание значения с полем. Плеер запускается вручную,
поддерживает обычные элементы управления и воспроизведение внутри мобильной
страницы. Ошибки и пустое значение объясняются отдельно автору и пользователю.

## Отображение и расчёт

- Столбцы показывают подписи и точные числа. Выбор категории открывает её итог.
- Круг показывает число или сумму в центре, доли и читаемую легенду. Отрицательные
  значения отклоняются до объединения малых категорий. Для среднего круг недоступен.
- Линия идёт по времени. Пропущенные дни или месяцы заполняются нулями для
  количества и суммы. У среднего отсутствие числовых данных даёт разрыв линии,
  а не вымышленный ноль. Точная дата и значение доступны через обычный выбор даты.
- «Показать данные» открывает семантическую таблицу с точными итогами, доступную
  с клавиатуры. Прокрутка широкой таблицы остаётся внутри блока.
- Категория «Остальные» сохраняет полный итог; среднее считается с весом по
  количеству числовых значений, а не как среднее средних.
- Пустые категории явно подписаны. Неизвестные варианты выбора показываются
  без раскрытия внутренних идентификаторов. Отсутствующие даты учитываются
  отдельно; в линию они не включаются.
- Дата использует общую политику таблиц: календарная дата остаётся датой,
  ISO-момент переводится в часовой пояс поля. Для поля «Дата» действует
  Europe/Moscow, для «Дата и время» — сохранённый часовой пояс.

Верстка учитывает ширину самого компонента, включая узкую колонку редактора
на широком экране. Легенда переносится под круг, числа не разрываются на телефоне.
Графики выполнены на SVG и HTML без новой библиотеки диаграмм. Плеер не загружает
видео заранее (`preload="none"`), не запускает его автоматически и не встраивает
произвольные страницы через iframe.

## Данные и права

Авторский и опубликованный запросы агрегируют все разрешённые строки, независимо
от размера страницы обычного списка. Обход выполняется пакетами по 200 строк.
Фильтры, представления, поиск, контекст карточки, вычисления и видимость экрана
используют общие серверные правила. Группа и числовое значение проверяются
по каноническим полям одной таблицы.

У опубликованного приложения сервер проверяет чтение обоих полей именно
для каждой участвующей строки. Одного объединения прав разных правил
недостаточно. Скрытое поле владельца не требуется передавать клиенту.
Вычисляемое значение со скрытой зависимостью не раскрывается через сумму.
Нерелевантная ошибочная формула в другом поле не мешает диаграмме.

Ответ содержит только итоговые точки и счётчики, без исходных строк и их ID.
Параметры чужой роли, таблицы или поля клиентом не принимаются. Курсоры обычных
списков и окна календаря/канбана для диаграмм отклоняются. Новая миграция не нужна.

## Границы и следующая очередь

Одна диаграмма показывает один ряд значений. Нет нескольких осей, произвольного
оформления серий, экспорта графика и действий приложения по нажатию на точку.
Выбор категории меняет только локальную детализацию. Максимум — 1 000 разных
категорий; при превышении показывается ошибка с предложением сузить отбор.
Столбцы и круг поддерживают 3–24 основные категории в контракте (в интерфейсе
5/10/15/20/24), плюс «Остальные»; по умолчанию 10.
Линия ограничена 60 периодами, включая пустые промежутки. Для более длинного
диапазона нужно выбрать месяцы или сузить отбор.

Видео поддерживает прямой URL и кодеки самого браузера. Загрузка и перекодирование
файлов, встраивание YouTube, редактор субтитров, отдельная галерея и компонент
файлов пока не реализованы. Изображение существовало ранее и сохранено.
Полные агрегаты пока обходят разрешённую выборку; отдельная оптимизация больших
объёмов остаётся в плане.

Этап 7 завершён частично. Следующая очередь — оформление и навигация приложения.
Галереи и файлы, события открытия экрана, автоматизации, общая группировка,
оптимизация больших выборок и полная приёмка остаются открытыми.
