# Первое приложение из своей таблицы — 26 октября 2026

Цель: человек со своей таблицей Excel должен получить понятный следующий шаг и дойти до работающего приложения без повторного выбора источника и лишней настройки.

## Что изменено

- Файл с одним видимым листом сразу открывает предварительный просмотр. Несколько листов и скрытые листы требуют явного выбора.
- Имена и типы колонок сначала показаны обычным текстом. Изменение доступно по кнопке «Настроить колонки».
- При пустом пространстве нет лишнего выбора между новой и существующей таблицей.
- После загрузки можно открыть данные или создать приложение именно на этой таблице. Если приложение уже есть, импорт возвращает к его настройке.
- Подготовка приложения без шаблона больше не ведёт через общий мастер с повторным выбором таблицы.
- Ошибки чтения и загрузки остаются на текущем шаге. Повтор загрузки использует тот же ключ операции; двойное нажатие не создаёт параллельные запросы.
- Создание черновика блокирует повторный запуск и переход к оставшимся листам. Неудачная навигация допускает повторный переход к уже созданному приложению.
- Исправлено одновременное отображение мобильных и настольных элементов управления из-за приоритета CSS.
- Перед публикацией предлагается проверить собственные данные и доступ. Указание заменить учебные примеры убрано из общего сценария.

## Проверка в браузере

В отдельном новом пространстве существующего владельца выполнен весь путь:

1. Загрузка настоящего XLSX с четырьмя товарами.
2. Просмотр данных, создание черновика и проверка экранов.
3. Настройка сотрудника и публикация приложения с закрытым доступом.
4. Обычный вход сотрудника по коду из письма.
5. Изменение остатка сотрудником на компьютере с 8 до 10.
6. Автоматическое обновление записи у владельца без перезагрузки.
7. Изменение остатка с 11 до 12 на экране шириной 390 px и повторная проверка обновления у владельца.

Для проверки доставки кода использована отдельная локальная копия сервера на порту 3104 с Mailpit. Авторизация проходила через обычный интерфейс. Основной сервер 3101 и его почтовые настройки не менялись. Производственная отправка почты этим тестом не проверялась. Регистрация нового глобального аккаунта не проходилась; начальное пустое состояние дополнительно покрывается компонентными тестами.

Снимки проверки находятся в `docs/audit/onboarding-2026-10-26/`:

- `import-after-desktop.jpg` — простой просмотр загружаемых данных;
- `import-after-mobile.jpg` — тот же шаг на телефоне;
- `import-result.jpg` — следующий шаг после загрузки;
- `owner-live-result.jpg` — обновлённые данные владельца;
- `staff-live-result-mobile.jpg` — сохранённая сотрудником запись на телефоне.
