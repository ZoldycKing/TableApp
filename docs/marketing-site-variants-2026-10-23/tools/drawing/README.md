# Ежедневник: модель и просмотр

Один условный предмет, два устойчивых компонента: обложка и бумажный блок. Это иллюстрация для миниатюры товара в маркетинговом демо. Пропорции заданы для узнаваемого силуэта; материал, допуски и производственные размеры не установлены. Один общий параллельный аксонометрический проектор используется для всех граней, деталей и экспортов.

Источники: описание родительской задачи; вымышленная геометрия в `model.js`. Скрытую конструкцию переплёта не изображаем. Разнесённый вид условно сдвигает бумажный блок от обложки и объясняет состав предмета, не способ производства.

Восстановление (Node.js):

```powershell
cd docs/marketing-site-variants-2026-10-23/tools/drawing
npm ci --ignore-scripts --no-audit --no-fund
node generate.cjs
node scripts/build-viewer.cjs drawing.json ../../assets/notebook-drawing.html
```

`node_modules/` игнорируется репозиторием. Версии закреплены в package-lock.json. Скрипты и ресурсы просмотрщика скопированы из установленного technical-drawing; выходной HTML встраивает Inter с лицензией, SVG-модель, worker и локальные библиотеки SVG/PNG/PDF. Он открывается с диска без сборки и сети.

Миниатюра `assets/notebook.svg` имеет холст 200 × 280 условных единиц и прозрачный фон. Просмотрщик использует лист 420 × 297 мм, NTS; масштаб просмотра не меняет экспорт. В экспорт попадают выбранные компоненты, линии и цвета, полный лист или обрезка с отступом 3 мм. PNG — 300 dpi, PDF — векторный.

На узком экране «Вписать» ориентируется на границы предмета и центрирует большой прокручиваемый лист. Экспорт сохраняет полный исходный лист A3 независимо от просмотра. В настольном виде вписывается весь лист.
