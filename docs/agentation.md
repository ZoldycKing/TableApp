# Agentation в TableApp

Панель для заметок на элементах интерфейса установлена из официальных npm-пакетов: `agentation@3.1.2` и `agentation-mcp@1.3.2`.

Она загружается только в `next dev`, на клиенте и на ширине от 768 px. На production-страницах не отображается. Глобальные горячие клавиши отключены, чтобы не мешать редактору таблиц. Исходное оформление приложения не меняется.

## Использование

1. Открыть локальный TableApp на компьютере.
2. Нажать кнопку Agentation справа внизу и выбрать элемент страницы.
3. Написать замечание и нажать `Add`.
4. Попросить Codex прочитать замечания Agentation. Можно также скопировать заметки кнопкой `Copy feedback` и вставить в чат.

## Локальный сервер

В установленном Codex зарегистрирован MCP-сервер `agentation`. После перезапуска Codex он запускается автоматически. Команда использует установленный в этом репозитории пакет, а не скачивает новую версию при каждом запуске.

Для ручного запуска:

```sh
pnpm agentation
pnpm agentation:doctor
```

Панель подключается к `http://127.0.0.1:4747`. Сервер слушает только loopback. В локальной конфигурации Codex разрешены источники `localhost` и `127.0.0.1` с портами 3101 и 3000. При смене порта нужно дополнить `AGENTATION_CORS_ORIGINS` в настройках MCP.

Заметки сохраняются локально: в браузере и SQLite-файле `~/.agentation/store.db`. Облачные API и webhooks не настроены. `doctor` проверяет конфигурацию Claude Code отдельно; предупреждение об отсутствии Claude Code не означает ошибку подключения Codex.

## Проверка установки

TypeScript и production-сборка прошли. Код панели и адрес MCP не обнаружены в клиентских production-чанках. Тестовая заметка создана через браузер, прочитана и закрыта настоящими MCP-вызовами. Подтверждены статус `MCP Connected`, удаление закрытой отметки и скрытие панели на ширине 390 px.

Инструкции: [Agentation](https://www.agentation.com/install), [MCP-сервер Agentation](https://www.agentation.com/mcp).
