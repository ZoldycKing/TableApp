# Инструкция для генерации экранов TableApp

Используй эту инструкцию при генерации конфигурации `AppV2` из таблиц. Верни конфигурацию по схеме TableApp, используй существующие ID таблиц, колонок, экранов и ролей.

1. Начни с экрана шириной 375 px. Для приложения покупателей выбери `appearance.presentation: "centered"`. Для рабочего приложения выбери `"workspace"`. Подключи один брендовый акцент для основных действий и активной навигации.
2. Выбирай раскладку по содержимому. Для товаров и услуг с фото или ценой используй `catalog`. Для записей с изображениями используй `cards`. Для разделов и категорий используй `tiles`. Для контактов, очередей и коротких записей используй `list`. В сетке привяжи изображение, если колонка с ним существует. Для записей без изображения интерфейс покажет инициалы или иконку.
3. На карточке заказа выведи статус и подтверждённую сумму выше свойств. Объединяй позиции по реальному номеру заказа и связывай состав с открытой записью. Размести клиента и дату в блоке свойств. Подставляй только поля из исходных данных. Показывай сумму заказа как сумму заказа, если данные описывают стоимость, и как сумму к оплате только при наличии соответствующего поля.
4. Для изменения статуса создай форму редактирования с одним полем выбора и отдельным действием сохранения, если по задаче роль имеет право менять статус этой записи. Для многострочного заказа используй отдельное действие на заказ целиком или на явно выбранную позицию. Цвет тега служит дополнительным признаком, а текст показывает реальный статус.
5. Контакты показывай с действиями звонка и письма. Историю заказов подключай по явной связи с клиентом. Проверяй доступ каждой роли к экрану, записи, полям и действиям отдельно.
