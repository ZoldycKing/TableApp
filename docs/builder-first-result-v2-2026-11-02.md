# Первое приложение после импорта

2 ноября 2026 года. Часть этапа 4 нового конструктора.

## Поведение

После подтверждённой загрузки в новые таблицы открывается черновик нового
конструктора. Дополнительная анкета с названием, назначением и повторным
выбором тех же таблиц не требуется. Каждый загруженный лист получает раздел
со списком, поиском и переходом в карточку выбранной строки. При нескольких
листах перед импортом можно выбрать, какой раздел откроется первым.

Названия и поля берутся из импортированных таблиц. Главное поле используется
для названия строки, второе подходящее поле для подписи. Карточка содержит
главное поле и до пяти других полей. Остальные поля доступны для настройки
в конструкторе. Новых учебных строк генератор не создаёт.

Первый вход показывает данные в режиме просмотра и одну необязательную
подсказку. Кнопка «Выбрать поля списка» открывает свойства готового списка.
Из карточки она возвращает к первому разделу. Подсказка закрывается без
изменения приложения; параметр первого входа удаляется из текущего адреса.

## Повторы и границы

- Результат импорта имеет отдельный восстанавливаемый адрес `/import/[runId]`.
  Его открытие и повтор подготовки возвращают один и тот же черновик.
- Идентификатор черновика вычисляется на сервере из пространства, автора и
  ключа импорта. Параллельные запросы сериализуются, готовый черновик не
  перестраивается. Название, поля и другие последующие правки сохраняются.
- Источником служат серверные квитанции импорта. Чужой автор, другое
  пространство, произвольный ключ и посторонняя основная таблица отклоняются.
- Ошибки отдельных листов остаются на экране импорта. Автоматический переход
  происходит, когда подтверждены все выбранные листы. Неудавшиеся можно
  повторить с тем же ключом без повторной записи успешных листов.
- Файл по-прежнему находится только в браузере. Перезагрузка до завершения
  импорта не восстанавливает содержимое файла; его потребуется выбрать снова.
  Сохранённый адрес результата восстанавливает уже подтверждённую загрузку.
- Дополнение существующей таблицы и возврат к подготовке существующего
  приложения сохраняют прежний путь. Для запуска только с дополнением строк
  автоматический новый черновик не создаётся.
- Автоматическая подготовка действует за существующим флагом конструктора
  `TABLEAPP_BUILDER_V2`. В development он включён; production требует явного
  включения. Рабочий сервер на 3101 не пересобирался в production.
- Создаётся только неопубликованный черновик. Генератор не предоставляет
  новые права на данные и не выполняет действия записи. Чтение в авторском
  просмотре использует права участника пространства.

## Проверка

Проверены генерация списка и карточки, собственные названия, несколько таблиц,
выбор первого раздела, главное поле после шестой колонки, пустые источники,
повторы, конкурирующие запросы, права и флаг включения. Проверены потеря ответа,
повтор неудачного листа, уход со страницы подготовки и первый переход к полям.

В браузере пройден путь отдельного временного аккаунта: кабинет → книга Excel
с листами «Проекты» и «Расходы» → проверка → выбор первого раздела → готовый
список → карточка → настройка дополнительного поля → сохранение → повторное
открытие результата. Остался один черновик, две таблицы и шесть исходных строк.
На ширинах 390 и 320 px горизонтального переполнения документа не было.
Временный аккаунт и его данные удалены после проверки. Сохранённые приложения
пространств дополнительно проверены на совместимость без записи изменений.

## Дальше

Первый результат и вход в настройку готовы. Полное обучение с сохраняемым
прогрессом, контекстной помощью, пропуском и возвратом ещё не реализовано.
Шаги реального сохранения и публикации подключаются после движка действий
и политики доступа. Перевод готовых шаблонов в новый конструктор также остаётся
отдельным этапом. Этот результат не означает завершения этапов 4–6.
