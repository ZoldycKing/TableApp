# MinIO для разработки и CI

Образ собирается из официальных исходников релиза
[`RELEASE.2025-10-15T17-29-55Z`](https://github.com/minio/minio/releases/tag/RELEASE.2025-10-15T17-29-55Z).
Архив проверяется по SHA-256 до сборки. Контекст Docker содержит только этот
каталог; настройки и данные TableApp в него не передаются.

Готовый образ `quay.io/minio/minio:latest` при первом запуске CI оказался
недоступен для анонимного скачивания. Сборка из исходников соответствует
[способу распространения community-версии MinIO](https://github.com/minio/minio#source-only-distribution).

```sh
docker compose build minio
docker compose up -d minio
```

Первая сборка скачивает Go-зависимости и занимает несколько минут; последующие
используют кэш Docker. Исходники MinIO не изменяются, их лицензия включена в образ
по адресу `/licenses/minio/LICENSE`. Этот сервис предназначен для локальной
разработки и временных CI-проверок; рабочее хранилище настраивается отдельно.
