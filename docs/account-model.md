# Модель аккаунта клиента

Один человек — один аккаунт платформы Scatta. Регистрация и вход по почте
общие для всех бизнесов. Личный кабинет (заказы, ремонты, записи, переписка)
живёт **только** внутри приложения конкретного бизнеса.

## Две стороны

| Сторона | Что видит человек |
| --- | --- |
| **Платформа** (`/my`, вход как сотрудник/клиент платформы) | Рабочие приложения (владелец / сотрудник) и отдельный список «Где вы клиент»: только название и логотип бизнеса со ссылкой на его приложение. Без заказов, статусов, сообщений и счётчиков. |
| **Приложение бизнеса** (`/a/{slug}`) | Кабинет этого бизнеса: свои записи, переписка, бронирования — в пределах роли и правил владения строками. |

Данные бизнесов на платформе не смешиваются. Сессия подтверждает только почту;
роль и видимость строк считаются заново по определению каждого приложения.

## Когда бизнес появляется в «Где вы клиент»

В списке только бизнесы, где у аккаунта уже есть **клиентская активность**:
профиль в `business_customers` для этой почты. Он создаётся, когда человек
заходит в бизнес как клиент (заказ с витрины, вопрос, кабинет после записи или
подтверждённый клиентский визит).

**Не** попадает в список:

- адрес просто стоит в allowlist / списке доступа, но человек туда не заходил;
- рабочие роли (сотрудник, владелец) — они остаются в «Ваших приложениях»;
- бизнес, где человек только сотрудник, без отдельной клиентской активности
  (такие рабочие приложения уже показаны выше на `/my`).

Каждый пункт — ссылка на клиентское приложение бизнеса. Никаких превью данных.

## Правила приватности

1. Платформенный `/my` не читает и не показывает строки, сообщения, статусы и
   счётчики чужих бизнесов.
2. Кабинет клиента открывается только по URL приложения бизнеса.
3. Внутри приложения клиент видит только свои записи (поле почты / ownership).
4. Сотрудник видит данные только своего бизнеса и в рамках ролей экранов.
5. Подмена идентификаторов между бизнесами и между клиентами отклоняется
   (см. [security-authorization.md](security-authorization.md)).

## Код

- Рабочий каталог: `listAccessibleApps` / `appsForStaff` —
  `apps/web/src/lib/customer-apps.ts`.
- Клиентский каталог: `listClientBusinesses` / `businessesForClient`.
- Страница: `apps/web/src/app/my/page.tsx`.
- Профиль клиента бизнеса: `ensureBusinessCustomer` —
  `apps/web/src/lib/business-customer.ts`.
